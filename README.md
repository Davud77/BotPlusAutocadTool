# BotPlusAutocadTool

Общий набор утилит для **AutoCAD 2025–2027, Windows x64**: оформление чертежей, нумерация, выбор объектов, очистка, обмен таблицами с Excel и пакетный выпуск PDF.

Проект объединяет предыдущие версии WM/WEAM AutoCAD Tools. Привычные имена команд сохранены. Revit в этот проект не входит.

**Версия 1.7.1:** описание продукта перенесено вправо от BotPlus AT. Проверка и скачивание обновлений встроены в окно сервиса: текущая и актуальная версии, прогресс, отмена и путь к проверенному установщику без дополнительных диалогов. [Инструкция 1.7.1](docs/USAGE-1.7.1.md), [проверки и ограничения](docs/VALIDATION.md).

## Установка

1. Скачайте `BotPlusAutocadTool-1.7.1-Setup.exe` из [GitHub Releases](https://github.com/Davud77/BotPlusAutocadTool/releases/latest). Локальная сборка находится в `artifacts/release`.
2. Закройте AutoCAD и Core Console.
3. Запустите установщик. Для установки всем пользователям потребуются права администратора; установка только для себя не требует повышения прав.
4. Запустите AutoCAD. В ленте появится вкладка **BotPlus AT**. В классическом интерфейсе доступны одноимённые меню и панель; команда `BOTPLUS_CLASSIC` показывает их вручную.

В мастере выберите установку для всех пользователей (с правами администратора) или только для себя. Путь определяется автоматически. Для текущего пользователя используется `%APPDATA%\Autodesk\ApplicationPlugins\BotPlusAutocadTool.bundle`.

Стандартная папка общей установки:

```text
C:\Program Files\Autodesk\ApplicationPlugins\BotPlusAutocadTool.bundle
```

Установщик выбирает DLL через манифест bundle: линия .NET 8 для AutoCAD 2025–2026, линия .NET 10 для 2027. Он не устанавливает AutoCAD и не отключает `SECURELOAD`. При необходимости проверьте `APPAUTOLOAD`, доверенный путь и сообщения AutoCAD.

Для ручной установки распакуйте ZIP с bundle и скопируйте `BotPlusAutocadTool.bundle` в стандартную папку `ApplicationPlugins`. Для отдельной проверки через `NETLOAD` выбирайте DLL именно вашей линии:

```text
Contents\Windows\2025-2026\BotPlusAutocadTool.dll
Contents\Windows\2027\BotPlusAutocadTool.dll
```

Не загружайте обе DLL одновременно. Если старый `WM_autocad.bundle` установлен отдельно, уберите его из автозагрузки перед использованием общего проекта: прежние имена команд могут конфликтовать. Новый установщик не удаляет чужие/старые bundle автоматически.

### Обновление и удаление

Для обновления закройте AutoCAD и запустите новый установщик. Он сначала удалит прежнюю зарегистрированную версию из выбранного каталога через её деинсталлятор, затем установит новую. Если обнаружена другая папка/режим установки, мастер остановится с указанием этой папки; сначала удалите ту копию через Windows. Удалить плагин можно через «Установленные приложения» Windows или `unins000.exe` в папке bundle. Пользовательские настройки в `%LOCALAPPDATA%\BotPlusAutocadTool` и прежние настройки автонумерации в `HKCU\Software\WEAM\AutoNum` сохраняются при удалении.

## Вставка форматки

На вкладке **BotPlus AT**, в панели «Выпуск», нажмите **Вставить форматку** или введите `BOTPLUS_INSERTFORMAT`, затем укажите точку вставки. Используется динамический блок `WM_FORMAT` из поставляемого `Assets/WM_FORMAT.dwg` с атрибутами. Форматка размещается в текущем пространстве на слое `WM_FORMAT`, поэтому её находит пакетная печать в ModelSpace. Размер и другие динамические параметры меняются стандартными свойствами блока AutoCAD.

Перед созданием блока плагин добавляет недостающие свойства штампа в DWG. Их начальное значение — пробел; существующие значения сохраняются. Поля атрибутов переносятся, привязываются к вставленному блоку и вычисляются сразу. Данные проекта можно заранее задать командой `WEAM_STAMP`; поля остаются связанными со свойствами DWG. Масштаб вставки задаётся через последнюю панель **Настройки** (по умолчанию 1).

## Автонумерация таблиц

В `AUTONUM` выберите тип **Ячейка в нескольких таблицах**, задайте строку и столбец (от 1, включая заголовки), начальный номер, шаг и порядок. Выделите нужные объекты AutoCAD TABLE: в одинаковой ячейке каждого появится следующий номер. Для таблиц слева направо выберите «Сортировка → Только горизонталь», для вертикального ряда — «Только вертикаль». Остальные ячейки сохраняются. Подробности объединённых и защищённых ячеек: [инструкция](docs/USAGE-1.3.0.md).

В 1.3.1 запись ограничена обычной текстовой ячейкой: поля и формулы целевой ячейки блокируют операцию, остальные поля, формулы, оформление и размеры TABLE не переписываются. Кнопка **Вставить таблицу в модель** в пакетной печати создаёт ведомость отмеченных номеров и наименований. Выбор папок доступен через **…**, открытие папки/первого PDF после печати включается в настройках. [Подробности 1.3.1](docs/USAGE-1.3.1.md).

Файл включён в установщик; исходный путь на компьютере автора не нужен. Если в DWG уже есть определение `WM_FORMAT`, используется оно — прежние вставки не переопределяются. При заблокированном слое команда сообщает об этом. Отмена выбора точки не вставляет объект.

## Сумма длин в строке состояния

Выделите линии, полилинии, дуги или сплайны: перед переключателем «МОДЕЛЬ» в нижней строке состояния появляется **Сумм. длина: 123,45**. Это длина в единицах DWG без пересчёта масштаба. Снимите выделение — индикатор скроется. Сумма пересчитывается при изменении выделения, завершении редактирования и переходе в другой документ. Кнопка `SUMLENGTH` с подробным окном сохраняется.

Если среда AutoCAD не предоставляет нативную панель, применяется механизм `MODEMACRO`, как в исходном LISP. Не запускайте одновременно старый LISP-реактор суммы длин, чтобы два инструмента не конкурировали за `MODEMACRO`.

## Проверка обновлений

Плагин проверяет [GitHub Releases](https://github.com/Davud77/BotPlusAutocadTool/releases) при каждом запуске и затем через каждые 24 часа, пока AutoCAD открыт. Новая версия показывается в разделе обновлений окна **Сервис**. Повторное автоматическое уведомление об уже показанной версии подавляется.

Кнопка **Проверить обновления** и команда `BOTPLUS_CHECKUPDATES` сразу запускают проверку в сервисе. Здесь отображаются текущая и актуальная версии. **Скачать актуальную** загружает установщик, в том числе для повторного скачивания установленной версии. Прогресс, отмена, ошибки и путь к проверенному EXE остаются в этом же окне; путь можно скопировать.

В сервисе можно отключить автопроверку и включить предварительные выпуски. По умолчанию выбираются только обычные опубликованные версии. При отсутствии сети автоматическая проверка молчит, ручная показывает ошибку внутри сервиса. После скачивания закройте AutoCAD и запустите EXE. [Подробная схема и проверка обновлений](docs/UPDATE-VALIDATION.md).

## Примеры

### Нумерация

Выберите текст или блоки, вызовите `AUTONUM`, задайте начальный номер, шаг и префикс, затем выберите порядок. Для атрибутов укажите нужный тег. Настройки сохраняются между сеансами.

### Выпуск PDF

Сохраните DWG и вызовите `WPLOT`. Настройте имя/слой форматок, выберите листы и порядок. По умолчанию используются имя блока и слой `WM_FORMAT`; лист и наименование читаются из атрибутов `ЛИСТ` и `НАИМЕНОВАНИЕ`.

- **Сшивка:** рядом с DWG создаётся `<имя DWG>_Binder.pdf`.
- **По листам:** отдельные PDF создаются в папке `<имя DWG>_Sheets`.

В окне печати выберите **1:1** для рамок в натуральном размере или **1:100** для рамок, увеличенных в 100 раз. Масштаб используется при распознавании бумаги и подготовке печати. Папка PDF по умолчанию пустая — результат сохраняется рядом с DWG; при необходимости задайте полный путь в окне печати или настройках. Масштаб вставки рамки и масштаб печати задаются отдельно.

Перед публикацией плагин спрашивает о сохранении DWG. Сохранение нужно для доступности подготовленных настроек фоновой печати. Поставляемые `BotPlus PDF.pc3` и `BotPlus PDF.pmp` автоматически устанавливаются в папку плоттеров активного AutoCAD. Стандартные, кратные и произвольные листы печатаются в заданном масштабе по рамке, без вписывания и центрирования; физический размер PDF также ограничивается рамкой. Четыре кнопки задают порядок обхода форматок и сохраняют правки списка. [Плоттер, размеры и проверки](docs/PRINTING-FORMATS.md). Гиперссылки ведут на главную страницу `https://weam.ru/` без параметров листа; повторяющиеся номера листов не приводят к перезаписи соседних файлов.

При ошибке обработки промежуточный PDF сохраняется в `%LOCALAPPDATA%\BotPlusAutocadTool\Publish`; путь выводится в командную строку. Итоговые имена файлов при повторном выпуске заменяются, поэтому сохраните нужные предыдущие результаты отдельно. Режим «По листам» не удаляет старые PDF от ранее выпущенных, но теперь исключённых листов.

### Редактирование TABLE в Excel

Вызовите `WEAM_TABLEEXCEL`, выберите TABLE. Плагин создаст XLSX и откроет его в назначенном приложении. Сохраните и закройте файл; когда чертёж активен и не выполняет команду, изменения импортируются после освобождения/стабилизации файла. Разные таблицы одного DWG можно редактировать независимо. Объединения, их снятие и добавленные строки/столбцы переносятся; редактор XLSX устанавливается отдельно. При ошибке файл сохраняется, его путь выводится в командную строку. Максимальный импорт — 2 000 000 ячеек.

## Совместимость

| AutoCAD | Целевой профиль | Проверка |
|---|---|---|
| 2025 | .NET 8, API 25.0.1 | Компиляция; загрузка в полном приложении ожидает проверки |
| 2026 | .NET 8, API 25.1.0 | Расширенные операции, TABLE/XLSX, компоновка WPF и настоящий PDF-драйвер в Core Console |
| 2027 | .NET 10, API установленного AutoCAD 2027 | Те же операции и PDF-публикация в Core Console |

AutoCAD 2027 требует перекомпиляции относительно 2025/2026, поэтому пакет содержит разные DLL. Обновления AutoCAD 2025/2026 также могут менять версию .NET хоста; используйте актуальные обновления Autodesk и проверяйте загрузку на своей установленной версии. [Совместимость Autodesk](https://help.autodesk.com/cloudhelp/2027/ENU/AutoCAD-Customization/files/GUID-A6C680F2-DE2E-418A-A182-E4884073338A.htm).

AutoCAD LT и другие CAD-платформы в текущую матрицу проверок не входят.

## Сборка из исходников

Нужны Windows x64, SDK .NET 8 и .NET 10, PowerShell 7 и доступ к NuGet. По умолчанию используются DLL установленной версии AutoCAD. Для отсутствующих 2025/2026/2027 проект получает официальные compile-only пакеты Autodesk; Autodesk DLL не включаются в дистрибутив. Принудительно выбрать NuGet можно параметром `-p:UseAutoCADNuGet=true`.

```powershell
git clone https://github.com/Davud77/BotPlusAutocadTool.git
cd BotPlusAutocadTool
dotnet build .\BotPlusAutocadTool.csproj -c Release -p:AutoCADVersion=2025
dotnet build .\BotPlusAutocadTool.csproj -c Release -p:AutoCADVersion=2026
dotnet build .\BotPlusAutocadTool.csproj -c Release -p:AutoCADVersion=2027
```

Если AutoCAD установлен в другом месте, добавьте `-p:AutoCADPath="D:\Autodesk\AutoCAD 2027"`. Сборка создаёт локальные файлы и **не устанавливает** плагин в AutoCAD.

### Bundle и EXE

```powershell
.\scripts\Build-Bundle.ps1
.\scripts\Build-Installer.ps1 -CompilerPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

Компилятор: Inno Setup 6.7.3 или совместимая версия из [официального источника](https://jrsoftware.org/isdl.php). Скрипт установщика проверяет наличие обеих линий DLL и запрещает включение Autodesk host DLL. Результаты находятся в `artifacts/release`: EXE, ZIP с bundle и `SHA256SUMS.txt`.

Повторяемость означает сборку из фиксированных исходников, версий зависимостей и сценария установщика. Побайтовая идентичность EXE между разными датами/компиляторами не заявляется; контрольные суммы относятся к конкретному выпуску.

### Проверки

```powershell
.\scripts\Verify-Structure.ps1
dotnet run --project .\tests\PdfChecks\PdfChecks.csproj -c Release
.\scripts\Test.ps1
.\scripts\Test.ps1 -Native -Year 2026
```

Нативные проверки используют `tests/AutoCADSmoke` и установленный AutoCAD 2026/2027 Core Console. Журналы сохраняются в `artifacts/validation`, снимки компоновки окон — в `tests/AutoCADSmoke/bin/Release/<framework>/results`. Происхождение модулей описано в [MERGE-NOTES.md](docs/MERGE-NOTES.md), результаты и границы проверок — в [VALIDATION.md](docs/VALIDATION.md).

Локальный журнал ошибок находится в `%LOCALAPPDATA%\BotPlusAutocadTool\Logs`; открыть его можно из окна «О программе». Он ограничен по размеру и не отправляется автоматически.

## Фактические ограничения

- Перед операциями очистки, разбиения и подготовки для заказчика используйте копию DWG: эти инструменты изменяют объекты.
- «Ограничение копирования» перехватывает команды открытого документа при загруженном плагине. Это не постоянная защита DWG от копирования в другом сеансе или программе.
- Полный цикл штатной/фоновой публикации и взаимодействие с Excel требуют проверки на рабочих конфигурациях; автоматические тесты PDF не заменяют проверку PDF-драйвера AutoCAD.
- Пользовательские настройки и промежуточные файлы находятся вне установленного bundle; временные файлы публикации пока не очищаются автоматически.
- EXE не подписан сертификатом издателя; Windows может показать издателя как неизвестного.
