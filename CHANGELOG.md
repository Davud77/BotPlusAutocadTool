# Изменения

## 1.2.1

- Исправлена ошибка `SettingsService / System.Text.Json, Version=9.0.0.0` при запуске AutoCAD 2026 на .NET 8. Настройки и разбор ответов GitHub используют уже поставляемую Newtonsoft.Json; прямой зависимости этих сервисов от System.Text.Json больше нет.
- Создание папки настроек и загрузка JSON защищены от ошибок; при недоступном или повреждённом файле используются значения по умолчанию. Формат настроек прежних версий сохранён.
- Весь обработчик проверки обновлений на Idle защищён от исключений. Неожиданный сбой отключает обработчик до перезапуска плагина, вместо повторяющихся окон JIT; временная ошибка сети не отключает ежедневные проверки.
- Добавлены регрессионные проверки настоящих исходников сервисов на .NET 8 и .NET 10, включая чтение старых настроек, недоступную папку и сбой Idle.
- Включены изменения 1.2.0: вкладка **BotPlus AT** и кнопка **Вставить форматку** с блоком `WM_FORMAT`.

## 1.2.0

- Вкладка ленты переименована в **BotPlus AT**. Имя проекта и установленного пакета остаётся BotPlusAutocadTool.
- Добавлена кнопка **Вставить форматку** в панели «Выпуск» и команда `BOTPLUS_INSERTFORMAT`.
- Исходный `Assets/WM_FORMAT.dwg` включён в обе линии DLL/установщик; путь на ПК автора не требуется.
- Импортируется определение `WM_FORMAT` с зависимостями, затем вставляется ссылка на слой `WM_FORMAT` в выбранной точке, с атрибутами. Если определение уже есть в чертеже, оно используется без замены существующих форматок. Для WBLOCK-файла без одноимённого определения используется его ModelSpace как определение блока.

## 1.1.1

- Индикатор суммы вставляется в начало строки состояния перед переключателем модели/листа.
- Лента создаётся после её фактической готовности и восстанавливается после смены рабочего пространства. Ошибка дополнительных сервисов не блокирует создание ленты.
- Манифест явно задаёт каталоги поиска зависимостей для обеих линий DLL.
- Перед обновлением установщик запускает деинсталлятор прежней зарегистрированной версии в выбранном режиме/каталоге. Настройки пользователя сохраняются; установка прерывается при неуспешном удалении.
- Проверка обновлений выполняется при каждом запуске AutoCAD и повторяется через 24 часа в работающем сеансе.

## 1.1.0

- Стандартный мастер EXE с выбором установки для всех пользователей либо текущего пользователя, определением правильного пути AutoCAD `ApplicationPlugins`, регистрацией удаления и обновлением существующей установки.
- Путь общей установки: `%ProgramFiles%\Autodesk\ApplicationPlugins`; пользовательской: `%APPDATA%\Autodesk\ApplicationPlugins`. Старый режим установки сохраняется при обновлении. Переключение режима не переносит и не удаляет другую установленную копию автоматически.
- Автоматическая фоновая проверка GitHub Releases раз в сутки при запуске AutoCAD и ручная команда `BOTPLUS_CHECKUPDATES`. Более старые версии, черновики и чужие URL отбрасываются. Предварительные версии включаются отдельной настройкой окна «Инфо».
- Проверка обновлений не устанавливает файлы самостоятельно: сообщение открывает страницу выпуска, установщик запускается после закрытия AutoCAD.
- Индикатор «Сумм. длина» в строке состояния. Обновляется при изменении предварительного выделения, завершении команды и смене документа; поддерживает линии, полилинии, дуги и сплайны по примеру LISP. Сумма выводится в единицах чертежа с двумя знаками после запятой; при снятии выделения индикатор скрывается.
- В средах без нативной панели используется `MODEMACRO`; прежнее значение восстанавливается, если другой инструмент не изменил его после плагина.

## 1.0.0

Первый объединённый выпуск: 17 имён команд, отдельные DLL для AutoCAD 2025–2026 и 2027, пакетная печать и обработка PDF, обмен TABLE/XLSX, документация и AGPLv3.
