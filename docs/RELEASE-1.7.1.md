- Описание «Инструменты для работы с чертежами AutoCAD» размещено справа от BotPlus AT в заголовке сервиса.
- Кнопка **Проверить обновления** сразу показывает текущую и актуальную версии в этом же окне.
- Добавлена кнопка **Скачать актуальную**, доступная также для повторного скачивания установленной версии. Прогресс, отмена, ошибки и путь к готовому установщику отображаются в сервисе, без дополнительных окон.
- Загрузка проверяется по SHA-256. После завершения можно скопировать путь, закрыть AutoCAD и запустить установщик.

Для установки закройте AutoCAD и запустите **BotPlusAutocadTool-1.7.1-Setup.exe**. ZIP предназначен для ручной установки bundle; SHA-256 находится в приложенном файле контрольных сумм.
