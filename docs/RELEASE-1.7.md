- В верхнюю панель печати добавлен выбор **CTB/STB**. Доступны совместимые стили текущего AutoCAD, **Из DWG** и **Без стиля**. Выбор сохраняется отдельно для файла и применяется ко всем выбранным листам.
- Панель стала компактнее: три строки фиксированной высоты. Она не сжимается и не прокручивается при уменьшении высоты окна — сокращается только список листов.
- Полные сведения о единицах и статусе доступны в подсказках. Минимальный размер окна 880×340 сохраняет все элементы доступными.

Сохраняются инструменты таблиц и встроенные настройки сервиса версии 1.6, печать с учётом единиц DWG, прозрачность, форматы ГОСТ и PDF с индексами.

Для установки закройте AutoCAD и запустите **BotPlusAutocadTool-1.7-Setup.exe**. ZIP предназначен для ручной установки bundle; SHA-256 находится в приложенном файле контрольных сумм.
