# Поиск и установка обновлений

Обновлено 30 октября 2026 для версии 1.7.1.

## Что выполняется автоматически

При загрузке плагина начинается фоновый HTTPS-запрос к `api.github.com/repos/Davud77/BotPlusAutocadTool/releases?per_page=30`; тайм-аут — 15 секунд. Далее запрос повторяется каждые 24 часа, пока AutoCAD открыт. При новом запуске выполняется новая проверка независимо от предыдущего сеанса.

Плагин сравнивает числовой номер установленной DLL с тегами опубликованных релизов. Автоматические уведомления отбрасывают черновики, более старые/равные версии и ссылки на другой репозиторий. Ручная проверка показывает последнюю опубликованную версию также при совпадении с установленной. Предварительные выпуски учитываются только при включённом флажке. Ветка main и неопубликованные файлы в поиск не входят.

Уведомление появляется, когда есть активный DWG и не выполняется команда. Повторное автоматическое уведомление об уже показанном теге подавляется. `BOTPLUS_CHECKUPDATES` выполняет ручную проверку, в том числе при выключенной автоматике, и показывает найденную версию, отсутствие обновления либо ошибку сети.

## Что делает пользователь

1. Открывает **Сервис** и нажимает **Проверить обновления**. Текущая версия видна сразу, актуальная появляется после ответа GitHub. Команда `BOTPLUS_CHECKUPDATES` открывает этот же раздел и запускает проверку.
2. Нажимает **Скачать актуальную**. Загрузка EXE начинается сразу. В том же окне видны прогресс, отмена и ошибки. EXE сохраняется в `%LOCALAPPDATA%\BotPlusAutocadTool\Updates\<версия>`. Размер и SHA-256 проверяются по метаданным GitHub либо `SHA256SUMS-<версия>.txt`.
3. После успешной проверки видит путь и кнопку **Скопировать путь**. Сохраняет чертежи и закрывает AutoCAD/Core Console.
4. Запускает скачанный установщик в прежнем режиме установки: для себя или для всех пользователей.

Загрузку можно отменить или повторить после ошибки. Частичный файл удаляется; предыдущая проверенная копия сохраняется при ошибке. AutoCAD автоматически не закрывается, установщик сам не запускается. Плагин не повышает права и не меняет SECURELOAD.

Встроенная панель доступна начиная с 1.7.1. Уже установленные старые DLL используют прежний интерфейс до установки новой версии; публикация релиза не меняет код на компьютере пользователя.

Установщик блокирует установку/удаление при работающем AutoCAD. В выбранном режиме он находит регистрацию этого продукта, проверяет каталог и путь деинсталлятора, удаляет прежнюю версию, устанавливает новый bundle с двумя линиями DLL и зависимостями. Папка настроек вне bundle сохраняется. Другая область установки автоматически не переносится; вручную запускать старый EXE не следует, установщик не является менеджером выбора последней версии.

## Проведённые проверки

- В 1.7.1 проверены текущая/равная/более старая опубликованная версия, отсутствие установщика, смена предварительных выпусков, состояния загрузки, отмена, повтор, закрытие и поздние результаты. Проверены привязки WPF обеих версий, кнопка скачивания и путь внутри сервиса в AutoCAD 2026/2027. Реальный HTTP-клиент ручной проверки сопоставлен с JSON GitHub. Журналы `v171-all-checks.log`, `v171-native27.log`, `v171-bundle-native26.log`, `v171-live-checks.log`.

- Реальный запрос того же HTTP-клиента, который использует плагин, и сравнение результатов с JSON GitHub. До публикации 1.3.1 все четыре прежних релиза были предварительными; обычная проверка обоснованно не находила обновлений.
- Автономный стенд с настоящими исходниками сервисов на .NET 8 и .NET 10: запуск и интервал 24 часа, ручная проверка, отключённая автоматика, занятый AutoCAD, отсутствие DWG, отсутствие новой версии, подавление повторов, отсутствие дублирующих запросов, отмена запроса и остановка подписок.
- Загрузчик на .NET 8/10: правильный EXE из того же тега и репозитория, прогресс, SHA-256 из digest и файла контрольных сумм, HTTP 403, неполная/повреждённая загрузка, отмена, удаление временного файла, повтор и сохранность прежнего проверенного EXE. Журнал: `artifacts/validation/release14/auto-download-checks.log`.
- Ошибки сети, HTTP 403, тайм-аут и повреждённый JSON: автоматическая проверка не открывает окно, ручная объясняет ошибку. Неожиданная ошибка хоста снимает обработчик Idle.
- Изолированные проверки установщика: обе линии DLL, совпадение версии с манифестом, удаление старой копии, очистка устаревших DLL, наличие шаблона/ExcelRuntime, удаление и сохранность настроек.

Журналы и скачанные контрольные файлы находятся в `artifacts/update-audit`; сборочные и нативные отчёты — в `artifacts/validation`. Тесты не заменяют рабочую копию в Program Files и не публикуют искусственный релиз для проверки уведомлений.

## Повторение

```powershell
dotnet run --project tests/UpdateChecks/UpdateChecks.csproj -c Release -f net8.0
dotnet run --project tests/UpdateChecks/UpdateChecks.csproj -c Release -f net10.0
# Сохраните JSON вышеуказанного GitHub API в artifacts/github-releases-audit.json:
dotnet run --project tests/UpdateChecks/UpdateChecks.csproj -c Release -f net8.0 -- --live artifacts/github-releases-audit.json
./scripts/Test-Installer.ps1 -InstallerPath <новый-EXE> -PreviousInstallerPath <предыдущий-EXE>
```
