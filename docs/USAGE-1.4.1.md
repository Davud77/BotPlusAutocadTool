# BotPlus AT 1.4.1

В закреплённой верхней части окна пакетной печати добавлена галочка **«Учитывать прозрачность»**. Она действует на объекты и слои, сохраняется между открытиями и применяется к сшивке и отдельным листам, в обычной и фоновой публикации. По умолчанию выключена.

Плагин записывает выбранное значение в параметры каждого листа. На время публикации он также задаёт `PLOTTRANSPARENCYOVERRIDE`: 0 без прозрачности, 2 с прозрачностью, затем восстанавливает прежнее значение, если пользователь его не изменил. Поэтому глобальная настройка другого компьютера не отменяет выбор галочки. [Описание Autodesk](https://help.autodesk.com/cloudhelp/2020/ENG/AutoCAD-Core/files/GUID-38F03A2C-6D36-4AD9-BBE0-9CA574BEF218.htm).

Исправлен порядок преобразования WCS → DCS при расчёте области печати: `Rotation × Displacement × PlaneToWorld`, затем обратная матрица. Прежний порядок мог смещать область при одновременно повёрнутом виде и ненулевом центре/направлении. При обычном виде сверху ошибка могла не проявляться. Это объясняет один из возможных вариантов различия между компьютерами; без проблемного DWG и настроек второго компьютера нельзя подтвердить именно его случай. [Формула Autodesk](https://help.autodesk.com/cloudhelp/2018/ENU/OARX-ManagedRefGuide/files/OREFNET-Autodesk_AutoCAD_DatabaseServices_PlotSettingsValidator_SetPlotWindowArea_PlotSettings_Extents2d.html).

Для сравнения печати рядом с DSD создаётся локальный файл `*.dsd.print.json`: версия плагина/AutoCAD, установленный PC3, центр и поворот вида, бумага, окно и прозрачность каждого листа. Путь к DSD выводится в командную строку. Эти файлы остаются на компьютере; отправка не выполняется автоматически.

Проверка: A2 при смещённом центре, повороте вида 90° и повёрнутой ПСК; точные координаты окна, размеры PDF и фактическая прозрачность в отрисованном результате. Для повторения: `scripts/Test-AutoCAD.ps1 -Year 2027 -Plot141 -Label transparency141` и `scripts/Test-PublishDesktop.ps1 -Year 2027 -Transparency141 -Label transparency141-27`. Обе проверки также доступны для 2026. Отрисовка: `scripts/Test-Plot141Pdf.py <папка результатов>`.

Закройте AutoCAD и запустите `BotPlusAutocadTool-1.4.1-Setup.exe`. Настройки версии 1.4 сохраняются. Функции версии 1.4 описаны в [USAGE-1.4.md](USAGE-1.4.md).
