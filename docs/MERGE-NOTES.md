## Сборки AutoCAD 2025–2027

Один исходный проект формирует две линии DLL:

- `AutoCADVersion=2025`: `net8.0-windows`, API AutoCAD 2025; эта линия предназначена для 2025–2026.
- `AutoCADVersion=2026`: `net8.0-windows`, API AutoCAD 2026; отдельный профиль для проверки 2026.
- `AutoCADVersion=2027`: `net10.0-windows`, API AutoCAD 2027.

Выходные и промежуточные каталоги разделены по версии AutoCAD. `Bundle/BotPlusAutocadTool.bundle/PackageContents.xml` выбирает DLL по диапазонам `R25.0–R25.1` и `R26.0`. Зависимости копируются локально; Autodesk DLL имеют `Private=False` и не должны входить в дистрибутив. Скрипт `scripts/Build-Bundle.ps1` собирает обе линии в новую staging-папку без установки в AutoCAD.

Основание: [таблица совместимости Autodesk](https://help.autodesk.com/cloudhelp/2027/ENU/AutoCAD-Customization/files/GUID-A6C680F2-DE2E-418A-A182-E4884073338A.htm) и [изменения SDK AutoCAD 2027](https://blog.autodesk.io/autocad-2027-sdk-what-every-plugin-developer-needs-to-know/). Поддержка версий — цель проекта; фактическая работоспособность будет подтверждаться сборкой и проверкой загрузки.

## Обновление: этап 3

После сообщения пользователя «давай дальше» выполнены компиляция и автоматические проверки. Актуальные результаты и оставшиеся проверки интерфейса приведены в `VALIDATION.md`.

Для отсутствующих AutoCAD 2025/2026 добавлены официальные compile-only NuGet-пакеты Autodesk (`AutoCAD.NET` 25.0.1 / 25.1.0). Теперь эти профили можно собрать без локальных API DLL; в дистрибутив Autodesk DLL не копируются. Конфликтующие `Microsoft.Extensions` согласованы с версиями хоста, для iText добавлен Bouncy Castle adapter.

Сервис обработки PDF подключён к событиям завершения/ошибки публикации. Временный PDF каждого задания находится в отдельной папке; `Idle` обрабатывает результат после завершения и освобождения процесса печати. Добавлено восстановление `FILEDIA` и `BACKGROUNDPLOT`, снятие подписок при закрытии документа/завершении плагина, запрет повторного старта до окончания обработки. Включено сохранение DWG перед публикацией, чтобы фоновой публикации были доступны созданные PageSetup; интерфейс заранее спрашивает о сохранении.

«Сшивка» создаёт `<имя DWG>_Binder.pdf`, «По листам» — отдельные страницы в `<имя DWG>_Sheets`. Обработка проверяет число страниц, сохраняет исходник при ошибке и учитывает книжную ориентацию. Имена отдельных файлов включают порядковый номер, поэтому повторяющийся номер листа не перезаписывает соседний лист. Восстановлено точное сохранение/чтение длинных полей штампа без добавления пробела при разрыве слова.
