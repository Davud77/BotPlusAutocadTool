# Окна, таблицы, форматка и настройки 1.3.0

Это локальный кандидат для проверки перед публикацией.

## Окна

Все 11 окон используют общие светлые стили, стандартные элементы WPF и системный заголовок. Окна можно растягивать; длинные формы прокручиваются. Основные кнопки вынесены в нижнюю панель. Штамп теперь редактируется через обычные поля, сгруппированные по проекту, исполнителям, изменениям и учёту. Данные штампа и имена DWG-свойств сохранены.

## Пример нумерации одинаковых таблиц

Пусть в модели расположены 20 таблиц, а номер нужен в третьей строке второго столбца каждой.

1. Запустите `AUTONUM`, выберите **Ячейка в нескольких таблицах**.
2. Укажите строку **3**, столбец **2**, начальный номер **1**, шаг **1**.
3. Выберите порядок: «Сортировка → Только горизонталь» для таблиц слева направо, «Только вертикаль» для таблиц сверху вниз. В режиме порядка выбора выбирайте таблицы последовательно щелчками.
4. Нажмите «Применить», выберите все нужные таблицы, завершите выбор Enter.

Счёт включает строки заголовков. Нумерация заменяет содержимое целевой ячейки; остальные ячейки не меняются. Префикс, суффикс и дополнение нулями работают и для таблиц. Повтор одного объекта в наборе не увеличивает номер.

Поддерживаются самостоятельные объекты AutoCAD TABLE. Набор линий и текстов, изображение таблицы, внешняя ссылка или таблица внутри блока автоматически не преобразуются. Для объединённой ячейки задайте её верхнюю левую строку и столбец. Если хотя бы в одной таблице нет ячейки, ячейка защищена или таблица недоступна для записи, операция останавливается до изменения содержимого. Диапазон целых номеров проверяется заранее.

## Форматка и штамп

Сначала задайте данные проекта в **Штамп** (`WEAM_STAMP`) и нажмите «Применить». Затем используйте **Вставить форматку** (`BOTPLUS_INSERTFORMAT`). Недостающие DWG-свойства создаются перед вставкой со значением из одного пробела. Существующие данные проекта не заменяются; явно введённый ранее дефис считается значением, его можно очистить в штампе.

Поля `CustomDP` копируются из исходной форматки, составные поля сохраняются. Ссылка поля формата листа привязывается к новой ссылке WM_FORMAT; после вставки поля вычисляются. Должности также связаны со свойствами штампа. Номер листа и страница остаются локальными атрибутами, начальное значение — 1; наименование чертежа можно задать для каждого листа в окне печати. Новый масштаб вставки применяется к следующим вставкам; существующие блоки не масштабируются.

Если DWG уже содержит определение WM_FORMAT, оно используется без перезаписи: геометрия и поля этого определения могут отличаться от поставляемого шаблона. Новая вставка получает поля, имеющиеся в этом определении. Ранее вставленные блоки с потерянными полями автоматически не перестраиваются.

## Масштабы и PDF

Для обычной модели: масштаб вставки **1**, печать **1:1**. Для модели с рамкой в 100 раз больше: масштаб вставки **100**, печать **1:100**. При подготовке бумаги габариты рамки делятся на выбранный знаменатель. Для точного стандартного формата задаётся явный масштаб 1/1 или 1/100; для нестандартной бумаги прежний резервный подбор с вписыванием сохраняется. Произвольные другие масштабы печати в этой версии не поддерживаются.

В одной операции выбирайте рамки одного масштаба. Для смешанного DWG выполните отдельную публикацию для каждого масштаба. Печать ищет форматки в ModelSpace, поэтому для этого сценария вставляйте их в модель. Папка PDF по умолчанию не задана: сшивка сохраняется рядом с DWG как `<DWG>_Binder.pdf`, отдельные листы — в `<DWG>_Sheets`. Сначала сохраните чертёж. В окне печати путь можно изменить для текущей операции.

## Настройки

Последняя панель ленты **Настройки** открывает `BOTPLUS_SETTINGS`.

| Параметр | По умолчанию |
|---|---|
| Масштаб вставки WM_FORMAT | 1 |
| Масштаб печати | 1:1 |
| Папка PDF | рядом с сохранённым DWG |
| Печать в фоне | включена |
| Масштаб расчёта суммы | 1/1 |
| Единицы длины / площади | мм / мм² |
| Проверка GitHub | при запуске AutoCAD, затем каждые 24 часа |
| Предварительные релизы | выключены |

Настройки пользователя хранятся в `%LOCALAPPDATA%\BotPlusAutocadTool\settings.json`. Кнопка «По умолчанию» меняет форму; «Сохранить» применяет изменения. «Отмена» закрывает форму без сохранения. Новые значения используются при следующем открытии соответствующей команды. Параметры формата автонумерации сохраняются в совместимом ключе реестра прежних версий.

## Подтверждённые проверки

- Сборки для API AutoCAD 2025, 2026 и 2027 без предупреждений.
- Реальный AutoCAD 2026/2027 Core Console: нумерация TABLE, сортировка, шаг/префикс, защита ячейки, отсутствие ячейки, переполнение; создание свойств и вычисление всех перенесённых полей, повторное обновление значения через DWG-свойства, масштаб вставки 100.
- Компоновка 11 окон и дополнительного режима таблиц; проверка пересчёта формы на размере 400×320.
- Настоящий `DWG To PDF.pc3`: по два листа в масштабах 1:1 и 1:100, контроль масштаба PageSetup, PDF, обрезка, гиперссылки и разделение на листы.
- Автономные регрессии .NET 8/10, настройки, XLSX, MTEXT и PDF.

Проверка компоновки выполняется модулем AutoCAD без ручного управления диалогами. Полный цикл кликов, перетаскивания окна на другой монитор и фоновая очередь печати в пользовательском сеансе остаются частью приёмки.
